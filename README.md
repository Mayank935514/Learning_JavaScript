📘 Learning JavaScript

A structured repository to learn JavaScript step by step — from basics to advanced concepts. This repository is designed for beginners and intermediate learners who want to build a strong JavaScript foundation through hands-on practice.

🧠 About

This repository covers core and advanced JavaScript concepts in a simple, organized way. Each topic is placed in its own folder so you can learn progressively and revise easily.

Topics include:

JavaScript Basics

Core Fundamentals

Functions

Strings

Arrays

Objects

Advanced Functions

DOM (Document Object Model)

Classes

Asynchronous JavaScript

Polyfills

🚀 Getting Started
Prerequisites

Basic programming knowledge (helpful but not mandatory)

Code editor (VS Code recommended)

Modern web browser

Clone the Repository
git clone https://github.com/Mayank935514/Learning_JavaScript.git
cd Learning_JavaScript

Optional (for Node.js practice)
npm install

📘 How to Use This Repository

Start from Basics_Of_JavaS

Move folder by folder in sequence

Run .js files using:

Browser console, or

Node.js (node filename.js)

Modify the code and experiment to understand concepts deeply

🎯 Purpose

Build a strong JavaScript foundation

Prepare for frontend frameworks (React, Angular, etc.)

Improve problem-solving skills

Use as revision notes for interviews
